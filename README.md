# NationOS

The complete Nigeria application, Next.js API backend, SQLite schema and documentation are in [frontend/](frontend/README.md).

Use Node.js 24, then run `npm ci`, `npm run db:init` and `npm run dev` inside frontend/. Open http://127.0.0.1:4173.

See [backend contracts](frontend/docs/backend-integration.md) and [data sources/model definitions](frontend/docs/data-and-models.md). No separate backend server or Supabase account is required.
